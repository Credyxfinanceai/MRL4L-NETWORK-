# MRL4 NETWORK

Plataforma independente de conteúdo, curadoria e conexão para o mercado de leilões.

## Desenvolvimento

- `npm install`
- `npm run dev`
- `npm run build`

## Antes de publicar para clientes

1. Substituir imagens ilustrativas por fotos autorizadas de lotes reais.
2. Inserir oportunidades reais somente após validar edital, valores, datas, status e URL oficial.
3. Conectar formulário a CRM/API segura e definir política de privacidade e retenção LGPD.
4. Inserir canais oficiais, telefone/WhatsApp autorizado, vídeos e agenda real.
5. Confirmar autorização de uso de marca e conteúdo MRL4.

Os cards e formulários atuais são demonstrativos. A plataforma não recebe lances nem substitui os canais oficiais do leilão.
